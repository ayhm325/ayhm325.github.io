DVLD Management System

A .NET 8 driving-license department system with a WPF client, ASP.NET Core Web API, SQL Server persistence and transactional business workflows. The documented solution separates HTTP concerns, application workflows, domain concepts, persistence and shared API contracts.

Thin Controllers + Application Use Cases
Repository + Shared Unit of Work
JWT + Policy-Based Authorization
Login Rate Limiting: 5 Requests / IP / Minute
Global Exception Handling + ProblemDetails
Unit + Integration Testing + Azure DevOps CI
