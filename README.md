## Design notes

The portfolio intentionally keeps the existing cinematic identity:
- particles
- holographic atmosphere
- glassmorphism
- custom cursor
- 3D tilt
- magnetic interactions
- Neural Network skills visualization
- DVLD architecture visualization

The PneumoDetect project and the old System Timeline are intentionally removed.

No framework is required; the portfolio remains pure HTML, CSS and JavaScript.
