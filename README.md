# Ayhm Obeidat Portfolio — Grand Line Code Edition

This version keeps the existing portfolio information and projects, but completely changes the visual language.

## New art direction

**Anime pirate-adventure atmosphere × .NET engineering**

- Deep ocean / Grand Line background
- Manga-style typography and impact treatment
- Wanted-poster inspired profile card
- Compass / navigation motifs
- Treasure-map / log-book panels
- Pirate-red + ocean-cyan + gold palette
- Programming symbols floating through the sea
- .NET "crew" skills network
- DVLD architecture presented as a route/map
- Responsive mobile navigation
- Cursor, magnetic buttons, 3D tilt and scroll reveal retained
- No character artwork is required; the One Piece influence is expressed through nautical, pirate, manga and adventure motifs.
